# Mohammad Abu Talib — Ab Initio Administrator

A one-page professional portfolio and cover-letter website for Mohammad Abu Talib, an Ab Initio Administrator open to administrator and consulting opportunities in India and globally remote.

## Live site

The production URL will be added here after the first Vercel deployment.

## Preview locally

This is a static website with no build step or environment variables.

1. Open a terminal in this repository.
2. Run `python3 -m http.server 4173`.
3. Visit `http://localhost:4173`.

Opening `index.html` directly also works for most checks, but a local web server more closely matches production behavior.

## Update the site

- Edit page content and metadata in `index.html`.
- Edit presentation and responsive styles in `assets/styles.css`.
- Edit motion, navigation highlighting, counters, and contact-form behavior in `assets/site.js`.
- Replace `assets/mohammad-abu-talib-headshot.jpg` to update the portrait while keeping the same filename.
- Replace `assets/Mohammad_Abu_Talib_Ab_Initio_Administrator.pdf` to update the downloadable résumé while keeping the same filename.

After replacing an asset, review the site on desktop and mobile before publishing.

## Deployment

The repository is connected to Vercel through its GitHub integration:

- Pushes to `main` deploy to production.
- Other branches receive preview deployments.
- The project is served directly from the repository root with no build command.

## Privacy

This public repository intentionally contains a professional portrait, résumé, phone number, and email address for recruiter access.
